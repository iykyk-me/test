# 오늘의 사용시간

Android 앱은 `UsageStatsManager`로 오늘 자정부터 현재까지의 앱별 foreground 사용시간을 조회하고, 상위 5개를 분 단위로 보여줍니다. 기록은 서버로 보내지 않고 기기 안에서만 사용합니다.

## 실행

1. Android Studio에서 이 `android` 폴더를 엽니다.
2. Android 기기 또는 에뮬레이터에서 앱을 실행합니다.
3. 앱의 `사용 정보 접근 허용` 버튼을 누릅니다.
4. 시스템 설정의 앱 목록에서 `오늘의 사용시간`을 허용한 뒤 앱으로 돌아옵니다.

사용 정보 접근은 일반 런타임 권한 팝업이 아니라 Android 시스템 설정에서 사용자가 직접 켜야 하는 특별 접근 권한입니다. 앱은 `onResume`에서 권한을 다시 확인해 허용 후 사용시간 목록을 표시합니다.

## 권한과 데이터

- `PACKAGE_USAGE_STATS`: 사용시간 조회에 필요합니다. manifest 선언만으로 허용되지 않으며 사용자가 시스템 설정에서 켜야 합니다.
- 앱 이름과 아이콘은 실행기 앱 조회 범위에서 찾고, 찾지 못한 경우 패키지 이름을 표시합니다. `QUERY_ALL_PACKAGES` 전체 패키지 권한은 요청하지 않습니다.
- 브라우저 미리보기의 목록은 화면 확인용 예시입니다. 실제 앱별 기록은 Android 앱에서 권한을 허용한 뒤에만 조회됩니다.
